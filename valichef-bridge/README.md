# Arquivos do Bridge

Coloque nesta pasta os arquivos reais do ValiChef Bridge antes de distribuir o pacote.

O instalador reconhece atualmente uma destas entradas:

- `valichef-bridge` — executável Linux;
- `index.js` — aplicação Node.js;
- `bridge.js` — aplicação Node.js;
- `main.py` — aplicação Python 3.

A versão em uso no mini PC de teste deve ser copiada para cá antes de considerar este pacote pronto para clientes.

Não salve tokens, credenciais, IDs secretos ou senhas neste repositório.
